### 機能一覧

| ID   | 機能                                     | 主な利用者 |
| :--- | :--------------------------------------- | :--------- |
| F-01 | メニューの閲覧                           | 客         |
| F-02 | 商品と個数の選択（金額の表示）           | 客         |
| F-03 | 支払いを済ませる                         | 客         |
| F-04 | 注文できたか確認（注文内容詳細を表示）   | 客         |
| F-05 | 注文を取消                               | 客         |
| F-06 | 注文内容一覧の確認                       | 店         |
| F-07 | 注文に対しての「対応（渡し）完了」の記録 | 店         |

### 作らないもの

| 機能                                     | 主な利用者 | 理由                                     |
| :--------------------------------------- | :--------- | :--------------------------------------- |
| ポイントカードやクーポンの利用           | 客         | 今のところ考えていない                   |
| 「できあがりました」の通知を注文者に行う | 客         | まずは注文して受け取れるところまででよい |
