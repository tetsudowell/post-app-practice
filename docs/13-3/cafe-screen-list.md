# 投稿アプリ 画面一覧

| ID    | 画面名                           | 役割                                                                                 | 主な利用者 |
| :---- | :------------------------------- | :----------------------------------------------------------------------------------- | :--------- |
| SC-01 | メニュー画面                     | その日のドリンクとフードを利用者に見せる。個数の選択と金額（カート）の確認までを行う | 利用者     |
| SC-02 | 支払画面                         | カートの商品を支払う（外部の決済サービスを利用）                                     | 利用者     |
| SC-03 | 注文内容確認（注文完了）画面     | 注文が完了（支払完了）したこと、注文の内容を確認する                                 | 利用者     |
| SC-04 | 注文取消画面                     | 注文の取消を行う画面                                                                 | 利用者     |
| SC-05 | 注文内容一覧画面（注文受付完了） | 客からの注文を一覧で表示                                                             | 店         |
| SC-06 | 注文内容詳細と対応状況入力画面   | 注文内容の詳細を確認する。加えて、対応済みの記録を行う                               |
