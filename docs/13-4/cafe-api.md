###エンドポイント一覧

| ID     | メソッド | エンドポイント | 何をするか                                     | 認証 |
| :----- | :------- | :------------- | :--------------------------------------------- | :--- |
| API-01 | GET      | api/menu       | メニュー一覧、カートアイテム選択と金額自動計算 | 不要 |
| API-02 | GET      | api/order      | カートのアイテムの合計金額を確認（支払は外部） | 不要 |
| API-04 | GET      | api/order/{id} | 客が自身の注文内容詳細を示す                   | 不要 |
| API-05 | DELETE   | api/order/{id} | 客が自身の注文を取り消す                       | 不要 |
| API-06 | GET      | api/orderlist  | 店が注文一覧詳細を示す                         | 必要 |
| API-06 | PUT      | api/orderlist  | 店が「対応済み」の場合、その旨、注文内容に反映 | 必要 |

#### API-02: 注文を登録する

- **メソッドとエンドポイント**: POST /api/orders
- **認証**: 不要
- **送るもの**: 本文で、注文する商品と合計金額
- **返すもの（うまくいったとき）**: 201。注文番号と、合計金額と、支払いの手続きに進むための行き先
- **返すもの（うまくいかなかったとき）**: 422（送ったものに不備があるとき、または選んだ商品が売り切れているとき）

#### API-06: 注文を受け渡し済みにする

- **メソッドとエンドポイント**: PUT /api/orders/{注文番号}
- **認証**: 必要
- **送るもの**: URLに注文番号。本文で、受け渡し済みにすること
- **返すもの（うまくいったとき）**: 200。書き換えたあとの注文1件（注文番号・商品と個数・合計金額・受け渡し済みであること）
- **返すもの（うまくいかなかったとき）**: 401（ログインしていないとき）／404（その注文番号の注文が無いとき）

###エラーレスポンス

| 起きること                                                             | ステータスコード | 返すもの                                             |
| :--------------------------------------------------------------------- | :--------------- | :--------------------------------------------------- |
| 送ったものに不備がある（注文の登録）                                   | 422              | 不備のあった項目と、その理由の文言                   |
| 売り切れの商品が注文された（注文の登録）                               | 422              | 「この商品は売り切れです」という文言                 |
| 指定した注文番号の注文が見つからない（お客さまの状況の確認・取り消し） | 404              | 「ご入力の注文番号の注文が見つかりません」という文言 |
| 指定した注文番号の注文が見つからない（店員の受け渡し）                 | 404              | 「該当する注文がありません」という文言               |
| ログインしていない（店員が使うもの）                                   | 401              | ログインが必要である旨の文言                         |
