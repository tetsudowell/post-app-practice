| ID     | メソッド | エンドポイント | 何をするか             | 認証 |
| :----- | :------- | :------------: | :--------------------- | ---- |

| API-03 | PUT      | api/posts/{id} | 投稿を更新する         | 必要 |
| API-04 | DELETE   | api/posts/{id} | 投稿を消す             | 必要 |
