# 投稿アプリの例外一覧

| 起きること                                                         | どこで気づくか       | そのときの処置                             | 利用者への知らせ             |
| :----------------------------------------------------------------- | :------------------- | :----------------------------------------- | :--------------------------- |
| ログインなしで投稿一覧を開こうとした                               | 投稿一覧を開くとき   | 元の画面に戻す                             | ログインが必要であること     |
| 他のユーザーの投稿を編集しようとした                               | 編集しようとする時   | 元の画面に戻す                             | 当該投稿の編集権限がないこと |
| 投稿に必要な必須項目が入力されていなかった                         | 投稿しようとする時   | 元の画面に戻す（編集内容はそのまま）       | 不足している項目と内容       |
| 1分以内に5回ログイン失敗した                                       | ログインする時       | 元に戻す（ログインは受け付けない：何分？） | ○分後に再度ログインが必要    |
| 更新しようとした投稿が、編集画面を開いているあいだに削除されていた | 投稿を探すとき       | やめて元に戻す                             | その投稿が見つからないこと   |
| 公開をやめようとした投稿が、すでに非公開になっていた               | 投稿の状態を見るとき | やめて元に戻す                             | すでに非公開であること       |
